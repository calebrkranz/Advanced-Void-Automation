# MV Storage and Autocrafting

## MV Storage, in-screen crafting and wireless access

Build and power an MV System. Open its custom storage HUD, search stored items with Find, and use its deposit/withdrawal controls. Selected withdrawal amount is separate from the total stored quantity.

The 3x3 manual crafting pattern is inside MV Storage. Place a pattern and use its output to craft from stored ingredients. The removed recipe-search controls and separate MV Pattern block are not required.

MV Links connect item networks to storage. Choose Transfer or Pull as needed. Filters, pauses and reach still apply. A linked automatic crafter may need both input and output directions permitted.

Sneak-use the Wireless MV Remote on the desired MV to bind it, then use the remote normally to open that MV HUD. MV, storage and power must be loaded in the same dimension. The remote does not force-load chunks. The retired Wireless MV Link access point is not required. Keep the wired MV Link Unit for automated item transfers.

Empty valuable storage and internal inventories before dismantling. Do not delete hidden inventory hosts to force a machine to break; they can hold real items.

## Universal Crafter and MV automation

The Universal Crafter uses a 3 x 3 sample recipe. Drag ingredients into the grid, then return the remaining cursor stack to your inventory before using its controls. Samples are returned; recipes consume ingredients from the connected MV storage.

Click Add automation to save and start a valid recipe immediately. No preliminary manual craft is needed. The sample grid clears after adding. Up to ten saved recipe boxes appear in Recipe / Queue. Click a box to stop, resume, remove or load it.

Mode: Auto crafts continuously while ingredients, MV room and power are available. Optional stock limits wait when their target is reached and resume after withdrawals. Crafted results return directly to MV.

Connect the Crafter directly through its network to MV Storage, or use an enabled bound MV Link through Transfer Pipes. Supply the Crafter with Watt power; remote MV input and output also require link transfer power. Missing materials or power cause a recoverable wait.

MV Storage keeps ordinary stackable items as counts. Use Find to filter stored names, including custom items. Shift-click deposits go into storage; deliberate grid placement sets the crafting recipe. MV Link has the same name-matching Find logic. Show all items resets its search; clicking an item selects its routing filter.
