# Advanced Void Automation

Start with a tree and build an automated factory above the void. **Advanced Void Automation (AVA)** is a Minecraft Bedrock add-on that connects Skyblock progression, machinery, power, and storage.

[Download on CurseForge](https://www.curseforge.com/minecraft-bedrock/addons/advanced-void-automation) 

## What you can build

- **An ME-inspired storage network.** Search and craft from MV Storage, connect production lines with MV Links, and automate recipes with the Universal Crafter.
- **A powered factory.** Move items and fluids through filtered routes, automate farms and sieves, and build battery banks, wireless power relays, and a nuclear reactor.
- **A metalworking workshop.** Melt metals, mix alloys, pour reusable casts, and recycle supported equipment in the seared smeltery.
- **An island that keeps growing.** Raise essence crops for tiered equipment, run a Void Ore Miner, and build flyable ships with cargo and passenger seats.

## Install

1. Download the .mcaddon from CurseForge and open it with Minecraft Bedrock.
2. Activate both **Advanced Void Automation BP** and **Advanced Void Automation RP** at the same version in your world settings.
3. Enable **Beta APIs**. Back up existing worlds before updating their packs.
4. In a Skyblock world, save a sapling, make a Wood Crook, and use surplus plants to compost dirt. Sieve the dirt for pebbles to start your first production line.

The add-on includes the behavior and resource packs. Use a separate void-world template or an existing Skyblock world if you want to start above the void. Education features and cheats are needed for Supremium armor's native flight.
