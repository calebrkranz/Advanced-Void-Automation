# Advanced Void Automation

**Build a skyblock factory in Minecraft Bedrock.** Start with a tree, sieve for your first resources, then connect farms, smelteries, and crafting machines to one storage network.

**[Download on CurseForge](https://www.curseforge.com/minecraft-bedrock/addons/advanced-void-automation)** · [Player guide](docs/README.md) · [Crafting recipes](docs/Crafting-Recipes.md)

## Install

1. Download the .mcaddon for your Bedrock version and open it with Minecraft.
2. Activate both **Advanced Void Automation BP** and **Advanced Void Automation RP** from the same release in your world settings.
3. Enable **Beta APIs** under Experiments. Back up existing worlds before updating their packs.
4. For a Skyblock start, use a separate void-world template or a world you have already prepared. The add-on download contains the two packs.

## What you can build

- **MV Storage and autocrafting.** Search and craft from centralized storage, connect machines with MV Links, and save repeat jobs in the Universal Crafter.
- **Power and production.** Build filtered item routes, fluid networks, battery banks, wireless power relays, and a nuclear reactor.
- **Smelteries and advanced materials.** Melt and cast metals, mix alloys, recycle supported gear, and turn surplus crops into Polymer.
- **Late-game projects.** Grow essence for tiered armor and tools, build a Void Ore Miner, or fly a ship with cargo and passengers.
